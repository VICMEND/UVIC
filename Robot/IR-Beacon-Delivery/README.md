# IR Beacon Delivery

**Language:** ROBOTC (C for the VEX Cortex)

## Goal

Drive a VEX clawbot through a delivery routine. After a button press it backs away from a nearby wall, spins until an infrared sensor sees a beacon, approaches with the sonar and IR sensors, drops a payload, and parks. Smaller files in this folder are earlier labs for driving, turning, and reading the IR sensor.
